# 번역기 구조

운영 방법은 [운영.md](운영.md), 설치·사용은 [README](../README.md) 에 있다.

## 1. 전체 구성

```
 내부망 PC 브라우저
        │ :7870 (UI_PORT)
        ▼
 [translator-gate]  python:3.12-slim · gateway.py (TCP 중계, 읽기 전용, 권한 없음)
        │  translator-pub (포트 공개용 일반 네트워크)
        │  translator-int (내부 전용: --internal, gateway_mode_ipv4=isolated)
        ▼
 [translator-app]   python:3.12-slim · uvicorn translator_app.main:app (:7860)
        │  화면(static/) + API + 문서 작업(data/jobs/)
        │  http://llm:8000/v1  (OpenAI 호환)
        ▼
 [pfdvlm-vllm]      도면 분석기의 vLLM 서버 (Qwen3.8-27B, --max-num-seqs 8)
                    pfdvlm-int (도면 분석기 쪽) + translator-int (별칭 llm, start 가 붙임)
```

- 이미지를 빌드하지 않는다. `python:3.12-slim` 에 코드(`translator_app/`, 읽기 전용)와 패키지(`cache/pylib/`, 읽기 전용), 자료(`data/`)를 바인드 마운트한다.
- 화면 컨테이너: `--read-only --tmpfs /tmp --cap-drop ALL --security-opt no-new-privileges --ulimit core=0`, 실행 계정 = run.sh 를 실행한 계정.
- 모델 서버 연결이 끊기면(도면 분석기 재시작) `scripts/linker.sh` 가 `docker events` 를 보고 다시 붙인다.

## 2. 요청 흐름

| 기능 | 흐름 |
|---|---|
| 텍스트 번역 | 화면 → `POST /api/translate/stream` → 문단 단위로 나눔(긴 문단은 문장 단위, `TEXT_CHUNK_CHARS`) → 캐시에 있는 문단은 바로, 나머지는 모델 서버에 스트리밍 요청 → NDJSON 이벤트로 글자 단위 전달. 새 입력이 오면 화면이 요청을 끊고, 서버는 모델 서버 요청을 닫아 생성을 멈춘다 |
| 문서 번역 | `POST /api/documents` → `data/jobs/<id>/` 에 저장 → 작업 대기열(`DOC_JOB_CONCURRENCY`) → 형식별 처리기가 글 조각(태그 포함) 추출 → `translate_batch` 가 약 2,500자·40개씩 묶어 JSON 스키마 구조화 출력으로 번역(앞 묶음 3쌍을 맥락으로) → 원래 파일 구조에 다시 씀 → 검수 → 내려받기. 보관 시간이 지나면 지움 |
| 이미지·스캔 PDF | 그림을 4MP 이하로 줄여 모델 서버에 보내 글자를 읽고 번역(Markdown) → DOCX 또는 PDF 덧붙임 쪽 |
| 글 다듬기 / 다른 표현 / 뜻풀이 | 각각 `POST /api/rewrite`, `/api/alternatives`, `/api/lookup` → 모델 서버 요청 1번 |
| 동시 요청 제한 | `PriorityLimiter`: 전체 `LLM_MAX_PARALLEL`(3), 문서 `LLM_DOC_PARALLEL`(2). 기다리는 텍스트 요청이 문서 요청보다 먼저 |

모델 서버 요청 공통: `chat_template_kwargs: {"enable_thinking": false}`(생각 모드 끔), 새어 나온 `<think>…</think>` 는 지움, 연결 오류는 2번 다시 시도(스트리밍 제외), 이미지를 거절하면 이미지 기능을 끈다. 상태 표시는 `GET /v1/models`(모델 이름·문맥 길이)와 `GET /metrics`(`vllm:num_requests_running`, `vllm:num_requests_waiting`)를 5초 캐시로 읽는다.

## 4. HTTP API

모든 응답은 JSON, 오류는 `{"detail": "<한국어 설명>"}`. `UI_AUTH=1` 이면 `/login`, `/api/login`, `/static/login.*`, `/static/styles.css`, `/health` 외에는 로그인이 필요하다(API 는 401, 화면은 `/login` 으로 이동).

| 메서드·경로 | 요청 | 응답 |
|---|---|---|
| `GET /health` | | `{"status":"ok"}` |
| `GET /api/status` | | 버전, 엔진, 모델(연결·이름·문맥 길이·이미지 지원·처리 중·대기·오류), 로그인, 한도, 지원 문서 형식 |
| `POST /api/translate` | `text` + 번역 옵션 | 번역문, 문단별 원문·번역, 용어집 적용, 감지 언어, 걸린 시간 |
| `POST /api/translate/stream` | 같음 | NDJSON: `start` → `delta`(글자 추가) / `unit`(문단 완료) → `done` (오류는 `error`) |
| `POST /api/alternatives` | `source`, `translation`, `span` + 옵션 | `{"alternatives": [...]}` (최대 5개) |
| `POST /api/rewrite` | `text`, `lang`, `style`, `context` | `{"text", "detected_lang"}` |
| `POST /api/lookup` | `term`, `context`, `source_lang`, `target_lang` | 뜻(번역·품사·설명)과 예문 |
| `GET/POST/PUT/DELETE /api/glossaries…` | | 용어집 목록·조회·생성·수정·삭제 |
| `GET /api/glossaries/{id}/export?format=csv\|tsv` | | 파일 (UTF-8 BOM, 엑셀용) |
| `POST /api/glossaries/{id}/import` | multipart `file`, `mode=append\|replace` | 용어집 |
| `GET /login`, `POST /api/login`, `POST /api/logout` | `{"username","password"}` | 쿠키 |
| `POST /api/documents` | multipart `file`, `options`(JSON: 번역 옵션 + `output`, `pdf_mode`) | 문서 작업 (202) |
| `GET /api/documents?ids=a,b` | | `{"jobs":[...]}` (모르는 번호는 빠짐, 전체 목록 없음) |
| `GET /api/documents/{id}` | | 문서 작업: 상태·진행률·남은 시간·주의·오류·보관 기한 |
| `GET /api/documents/{id}/download` | | 번역본 파일 |
| `GET /api/documents/{id}/preview` | | `{"text"}` (앞 2만 자) |
| `GET /api/documents/{id}/report` | | 검수 결과 `{"items":[{"source","target","issue"}]}` |
| `POST /api/documents/{id}/cancel`, `DELETE /api/documents/{id}` | | 취소 / 파일까지 삭제 |

번역 옵션: `source_lang`(`auto` 가능), `target_lang`, `formality`(`auto`·`formal`·`informal`·`plain`·`gaejoshik`), `context`, `use_glossary`, `glossary_id`, `glossary_entries`.

## 5. 환경 변수

`run.sh start` 가 `config.env` 를 읽어 화면 컨테이너에 넘긴다.

| 환경 변수 | 값 (run.sh 기준) | config.env |
|---|---|---|
| `APP_HOST` / `APP_PORT` | `0.0.0.0` / `7860` | — |
| `TRANSLATOR_DATA_DIR` | `/workspace/data` | — |
| `GLOSSARY_PATH` | `/workspace/data/glossary/default.json` | — |
| `ENGINE_TYPE` | `openai_compatible` (시험: `mock`) | — |
| `LLM_BASE_URL` | `http://llm:8000/v1` 또는 `LLM_URL` | `LLM_PORT`, `LLM_URL` |
| `LLM_MODEL`, `LLM_API_KEY` | 비움(자동), `EMPTY` | 같은 이름 |
| `LLM_MAX_PARALLEL` / `LLM_DOC_PARALLEL` | `3` / `2` | 같은 이름 |
| `DOC_MAX_MB` / `DOC_RETENTION_HOURS` / `DOC_JOB_CONCURRENCY` | `50` / `24` / `2` | 같은 이름 |
| `UI_AUTH` / `UI_USER` / `UI_PASSWORD` | `0` / `translator` / (비움) | 같은 이름. 비밀번호는 명령줄이 아닌 환경으로 넘긴다 |
| `SESSION_SECRET` | `state/session_secret` | — |
| `TZ` | `KST-9` | `CONTAINER_TZ` |

그 밖에 앱 기본값으로 두는 것: `LLM_TIMEOUT`(600초), `LLM_TEMPERATURE`, `LLM_EXTRA_BODY`, `LLM_VISION`(auto), `TEXT_MAX_CHARS`(30000), `TEXT_CHUNK_CHARS`(1200), `SEGMENT_CACHE_SIZE`(4096), `DOC_MAX_CHARS`(600000), `CORS_ALLOW_ORIGINS`.

## 6. 개발

```bash
python -m pip install -e ".[dev]"
```

```bash
python -m pytest -q
```

모델 서버 없이 화면을 띄울 때는 시험용 엔진을 쓴다.

```bash
ENGINE_TYPE=mock TRANSLATOR_DATA_DIR=./data python -m uvicorn translator_app.main:app --port 7860
```

가짜 모델 서버로 실제 요청 흐름을 볼 때:

```bash
python dev/fake_vllm.py --port 8000 --delay-ms 20
```

```bash
LLM_BASE_URL=http://127.0.0.1:8000/v1 ENGINE_TYPE=openai_compatible TRANSLATOR_DATA_DIR=./data python -m uvicorn translator_app.main:app --port 7860
```

가짜 모델 서버의 번역은 `[KO] 원문` 꼴(대상 언어는 지시문의 `Target language: …` 줄에서 읽음)이고, JSON 스키마 요청에는 배열 길이를 맞춘 객체를, 이미지에는 고정 문구를 돌려준다. `--fail-rate` 로 오류를, `--delay-ms` 로 느린 생성을 흉내 낸다.
